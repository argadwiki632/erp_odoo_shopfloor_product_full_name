Shop Floor Full Product Names

See the complete name. Keep work moving.

Long product names wrap onto multiple lines in Shop Floor cards instead of being cut off.

Clear product names on the shop floor

When a product name is longer than the available space, Shop Floor normally truncates it. This add-on lets the text wrap naturally so operators can read the complete name without changing product data or card content.
